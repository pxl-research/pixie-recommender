# Conversation Scenarios

These examples demonstrate the refreshed conversation loop. Prompts generated by the refinement LLM and the result intro always remain under 120 tekens (checked via simple counts shown below).

## 1. Happy path – direct answer

- **Request**: `Ik zoek een laptop met touchscreen`
- **Pixie response**: `{"type": "answer", "conversation_id": "9b5c2f7b-41aa-4be3-9b77-2040cc8d4d18"}`
- **Result intro** (`58 tekens`): `Je vroeg om laptopvoorkeuren, ik toon de beste matches.`
- **Excerpt of message**:

   ```text
  Je vroeg om laptopvoorkeuren, ik toon de beste matches.
  Resultaten voor laptops:
  - schermgrootte: 14" | merk: Dell | prijs: 1199
  - schermgrootte: 13" | merk: HP | prijs: 1099
  ```

## 2. Te veel resultaten → vraag → antwoord

1. **Request**: `Heb je gaming laptops?`
2. **Loop manager** (`ask_user`, `conversation_id`: `dca6a79d-4388-4bc1-86f8-5fa0186d6ad0`)
   - **Follow-up question** (`96 tekens`): `Er zijn nog 42 resultaten voor gaming laptops; welke prijsrange past het best?`
3. **User reply**: `Doe maar tussen 1200 en 1600 euro`
4. **Final response**: `type=answer`
   - **Result intro** (`62 tekens`): `Je prijsvoorkeur is verwerkt; dit zijn passende gaming laptops.`
      - **Excerpt**:

      ```text
     Je prijsvoorkeur is verwerkt; dit zijn passende gaming laptops.
     Resultaten voor gaming laptops:
     - merk: ASUS | prijs: 1499 | gpu: RTX 4070
     - merk: Lenovo | prijs: 1299 | gpu: RTX 4060
     ```

## 3. Geen resultaten na verfijning

1. **Request**: `Ik zoek een kinderkamer bureau`
2. **Loop manager question** (`87 tekens`): `Er zijn nog 18 resultaten voor bureaus; welke kleur moet het blad hebben?`
3. **User reply**: `Lichtgroen`
4. **Pixie response**: `type=no_results`
   - **Result intro** (`66 tekens`): `Ik heb geen matches gevonden op basis van je groen-kleur voorkeur.`
   - **Payload text**: `Ik heb geen matches gevonden op basis van je groen-kleur voorkeur.
Geen producten gevonden`

Use the `conversation_id` returned in step 2 for all follow-up calls to `/ask`. Conversations expire automatically once they exceed the configured `PIXIE_CONVERSATION_TTL_MINUTES`.
